# ألماني من الصفر — ملفات الرفع

## محتوى المجلد
| الملف | وظيفته |
|---|---|
| index.html | الموقع نفسه (الكود والتصميم) |
| config.js | الإعدادات: رابط المساعد الذكي |
| data/ | الدروس والقاموس والمواضيع والأفعال الشاذة والتمارين والموضوعات والحوارات ونماذج الامتحانات |
| data/dict.json | نسخة JSON من القاموس (للاحتفاظ بيها، الموقع مش بيستخدمها) |
| manifest.webmanifest + sw.js | تثبيت الموقع كأبلكيشن والشغل من غير نت |
| icons/ | أيقونات الموقع وصورة المشاركة |
| robots.txt + sitemap.xml | لجوجل |
| api/ | كود المساعد الذكي (Cloudflare Worker) وشرحه |

## الرفع
1. استبدل `YOUR-DOMAIN.com` بالدومين بتاعك في 3 ملفات: index.html و robots.txt و sitemap.xml.
2. ارفع كل الملفات والمجلدات زي ما هي على الاستضافة (Cloudflare Pages أو Netlify أو أي استضافة عادية)، ما عدا مجلد api/، ده بيتحط على Cloudflare Workers لوحده.
3. لازم الموقع يشتغل على https عشان التثبيت كأبلكيشن والشغل من غير نت يشتغلوا.
4. سجّل الموقع في Google Search Console وابعت sitemap.xml.

## لما ترفع تحديث
- ارفع كل الملفات الجديدة مكان القديمة.
- الموقع بيجيب أحدث نسخة من السيرفر لوحده، والطلاب بيشوفوا التحديث من أول ما يفتحوا الصفحة أو يعملوا reload.
- للاحتياط: غيّر `VERSION` في sw.js (مثلًا من "v13" لـ "v14")، وغيّر `?v=13` في index.html لنفس الرقم.

## المساعد الذكي
الموقع كله شغال من غيره. لتفعيل الشات وتصحيح الكتابة وترجمة الصور: اتبع api/README.md.


## قاعدة البيانات والحسابات ولوحة التحكم
شوف ملف DATABASE.md: فيه خطوات تشغيل حسابات الطلاب وحفظ التقدّم ولوحة التحكم على Cloudflare.
